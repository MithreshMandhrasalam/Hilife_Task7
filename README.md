# HiLife Task 7 Portal

A unified employee portal that integrates three components:
1. **Login & Registration (Task 4)**: Basic authentication and session management.
2. **Employee Directory (Task 5)**: Search and filter tools with real-time age calculation.
3. **Work Timer (Task 6)**: A persistent stopwatch with lap logging.

## Tech Stack
- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)
